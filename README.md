# Веб-портал для навчання дітей «Розумники» (Client-side JavaScript)

Лабораторна робота №4 з дисципліни «Розробник фронтенду програмних систем».
Тема: Реалізація клієнтських скриптів за допомогою JS.
Варіант: №4.

## Реалізований функціонал (Варіант 4)
- **Головна сторінка (`index.html`)**:
  - Падаючі іграшки на фоні шапки з розрахунком висоти відносно великої літери назви.
  - Інтерактивна 3D фліп-картка автора курсу з девізом/цитатою на звороті.
  - Динамічна адаптація теми за часом доби (з 6:00 до 21:00 фон на 40% світліший).
- **Сторінка «Наші курси» (`courses.html`)**:
  - Інтерактивний навігаційний акордеон у лівому верхньому кутку з описом курсів.
- **Сторінка «Зворотній зв'язок» (`feedback.html`)**:
  - Динамічна спливаюча підказка (tooltip) та підсвічування поля «Детально».
